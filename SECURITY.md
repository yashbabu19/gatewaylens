# Security policy

GatewayLens is an early-stage static OpenAPI checker and is not a runtime security product. Do not use a clean report as evidence that an API is secure.

Please do not open public issues containing secrets, credentials, private API definitions, or sensitive operational information. For a suspected vulnerability in this project, contact the repository maintainer privately before publishing technical details.

The project currently has no guaranteed response-time SLA or supported release branch.
